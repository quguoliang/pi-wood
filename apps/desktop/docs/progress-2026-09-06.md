## 本批次已完成

### 终端（macOS 可用性修复）

- `resolveShell()` 增加 darwin/Linux 分支：此前默认拉起 `powershell.exe`（macOS 不存在），PTY 子进程秒退，面板只剩「[进程退出]」；现按 `$SHELL`（缺省 zsh/bash）以 `-l` 登录态启动，Windows 三分支不变。
- 退出提示带退出码：`[进程退出 code=N]`。
- 首次创建后补发 `termResize`（`termCreate` 异步返回前 `fit.fit()` 已改变宽度，pty 与 xterm 尺寸脱钩导致 zsh promptcr 的整行空格填充折行、每行提示符上方残留反色 `%`）；另加 `ResizeObserver` 保证面板/窗口尺寸变化时持续同步。

### 浏览器（截图流 → 真·内嵌浏览器）

- 面板从 headless Playwright 截图查看器改为 `<webview>` 真实页面：可点击/输入/滚动/登录（`persist:piwood-browser` 分区，登录态跨会话保留）；工具栏补后退/前进/刷新；地址栏跟随真实导航（含页内跳转）。
- localhost dev server 预览不再绕道 playwright——此前 `browser:navigate` 对 localhost 会 8s 超时报错；本地服务芯片一键直达。
- 主窗口 `webPreferences` 开启 `webviewTag`；agent 侧 `browser_*` 工具仍走原 headless 服务，与面板解耦。

### 文件面板（VSCode 级重构）

- 文件树改用 **react-arborist**（虚拟滚动/键盘导航/ARIA 开箱即用）+ 自绘 VSCode 行渲染：22px 行高、旋转 chevron、逐级缩进参考线、整行选中高亮、目录优先排序；懒加载子目录经 onToggle ensureChildren 合并进嵌套 data（v3 移除了 onLoadChildren）。
- 文件类型彩色图标（vscode-icons 主题）：`@iconify-json/vscode-icons` 全量经 `addCollection` **离线**注册，50+ 扩展名映射（`lib/file-icons.tsx`），未命中回退 default-file；搜索结果行同款样式。
- 布局改左右分栏：左侧面包屑 + 编辑器，右侧「筛选文件…」+ 文件树（筛选输入即搜，250ms 防抖），中间分隔条可拖拽调宽；空态为「打开文件 / 从工作区目录树中选择文件」。

### 编辑器（CodeMirror → Monaco）

- 文件预览/编辑切换为 **Monaco**（`@monaco-editor/react` + monaco-editor 0.56，VS Code 同款引擎）：全语言语法高亮开箱即用（此前仅 js/ts 有高亮），JSON 自带校验。
- 离线装配（`lib/monaco-setup.ts`）：`loader.config({ monaco })` 喂本地 npm 包 + 5 个语言 worker 经 vite `?worker` 打包（注意 monaco 0.56 exports 深路径映射，须用 `monaco-editor/editor/editor.worker.js?worker` 形式）；主题 `piwood-dark` 透明背景融入面板。
- 默认可编辑（只读模式已删）；`Cmd/Ctrl+S` 经 `editor.addCommand` 保存；审查跳转改 `revealLineInCenter`。

### 添加到对话（选中内容 → 引用上下文）

- 编辑器选中后浮出「添加到对话」标签（onMouseDown 抢在失焦前触发）；右键菜单项 + `Cmd/Ctrl+Shift+L` 三入口等价。
- 新增 `stores/pending-context-store.ts`：片段按 `path:start-end` 去重、上限 8。
- composer 芯片条渲染 `文件名 起-止` 芯片（与文件附件芯片并排）：点击回跳文件面板对应行（复用 requestFile → revealLineInCenter），× 移除。
- 发送时把片段展开为带 `path:起-止` 头的代码块拼进消息（agent 侧零协议改动）；`/btw` 侧边问答与「作为目标发送」同样支持；发送成功即清空。
