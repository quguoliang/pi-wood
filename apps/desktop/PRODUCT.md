# Product

<!-- impeccable:product-schema 1 -->

## Platform

adaptive

## Users

需要在本机项目中与编码 Agent 协作的开发者。

## Product Purpose

pi-wood 在同一个桌面工作台中组织项目、项目内会话、Agent 对话、运行时信息和文件/终端/浏览器/变更工具。

## Operating Context

macOS 桌面环境；用户在一个项目内持续发起和恢复编码会话，并随时查看执行上下文与工作台内容。

## Capabilities and Constraints

- 项目拥有各自的会话树；会话不能脱离项目展示。
- 三栏工作台可调整宽度，左右栏可收起。
- 使用 Electron、React、TypeScript 和 Lucide 图标。
- 保持深色高密度桌面应用体验，支持键盘操作与焦点状态。

## Brand Commitments

- 产品名为 pi-wood。
- UI 以 `/Users/admin/Desktop/personal/D/dsh-desktop` 的真实实现和已提供的 Codex UI 设计规范为基准。

## Product Principles

- 项目与会话的归属必须一眼可见。
- 对话内容优先，工具按需出现。
- 密度高但不拥挤，状态用层级而非装饰表达。
